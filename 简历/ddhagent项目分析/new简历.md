## 个人项目

::: start
**城市应急调度平台**
::: end

- **项目简介**：面向暴雨防汛、大型活动等突发场景的调度平台，负责应急工单发布与高并发抢单链路设计。
    
- **技术栈**：`Java / Spring Boot` `MySQL` `Redis / Lua` `RabbitMQ`
    
- **项目亮点**：
    
    - **原子抢单链路**：设计 **Redis + Lua 原子抢单方案**，将资格校验、名额扣减和重复提交校验封装为原子操作，并通过 **MySQL 唯一索引**保障最终幂等；在本地固定压测环境、200 并发下，相比 MySQL 同步处理基线，接口吞吐量由 **474 QPS 提升至 886 QPS**，压测期间未出现超卖。
        
    - **异步落库与削峰**：针对同步落库占用应用线程与数据库连接、峰值请求容易阻塞的问题，引入 **RabbitMQ 异步解耦**请求受理与数据持久化，并采用 **Redis 预扣 + 异步落库**缩短请求链路；在相同条件下，请求受理接口吞吐量达到 **1123 QPS**，**P99 为 375ms**，压测期间无 5xx 及连接池超时。
        
    - **可靠消息与数据一致性**：针对消息丢失、重复消费及 Redis 与 MySQL 状态不一致问题，构建 **Publisher Confirm、手动 ACK、死信重试与 Outbox 补发**的消息可靠性闭环，并通过**唯一索引、业务幂等键和定时对账**完成重复拦截与异常补偿；故障演练中未产生重复业务记录，异常数据可在一个对账周期内完成修复。
