项目简介：
面向自动驾驶硬件研发部门的企业级 AI 助手，飞书 / Web 双端上线，覆盖器件选型、项目管理、测试验证等场景。作为核心开发者，主导设计"LLM 规划 + 确定性执行"的Multi-Agent 架构与器件选型领域的多模态 RAG 系统。

核心技术栈：：`Python / FastAPI` `Claude Agent SDK / MCP` `ANN / maxsim` `PostgreSql / pgvector` `Redis`

项目亮点：

Multi-Agent 架构：针对任务规划与执行强耦合导致单点故障、无法并行的问题。主导设计LeadAgent 统一生成结构化计划，服务端做 schema 校验、DAG 构建与依赖调度，专家 Agent 只负责执行；结果聚合前引入仲裁校验层检测跨 Agent 输出矛盾。复杂任务平均耗时 60s →35s（↓42%）。

多模态检索：针对传统文本 RAG 系统性答不出硬件图表曲线类问题。设计视觉原生检索方案：跳过 OCR，用ColQwen2 对整页图像做 patch 级多向量 embedding，ANN 粗排 + MaxSim 精排定位答案区域，分数不足时降级文本双路兜底。图表类问题准确率 35% →73%。

结构化抽取管线：构建硬件数据知识库，采用多量纲单位归一化、数字/扫描 PDF 分流、跨表交叉校验后入库 PostgreSQL；查询侧用预置 SQL 模板，LLM 仅做参数抽取，规避幻觉与注入风险。抽取准确率 62% →91%，支持跨文档精确范围查询。


多租户资源治理：高并发下简单请求被复杂任务挤占、重试请求级联挤爆资源池。主导设计资源治理层：按模型调用/DB连接/下游调用分类设并发上限，公平轮转替代 FIFO 分配执行槠位，重试请求降权隔离。简单请求 P95 延迟 15s →5s（↓67%），资源利用率↑35%。
