momenta



- **核心参与项目**：DDH Multi-Agent 智能助手平台

- **项目简介**：面向自动驾驶硬件研发部门的企业级 AI 助手，接入飞书群聊，覆盖器件选型、项目管理、测试验证等场景。作为核心开发者，负责 Multi-Agent 任务编排与器件选型领域的多模态 RAG 系统建设。

- **技术栈**：`Python / FastAPI` `Claude Agent SDK / MCP` `ANN / MaxSim` `PostgreSQL / pgvector` `Redis`

- **项目亮点**：

  - **Multi-Agent 架构**：针对任务规划与执行强耦合导致单点故障、无法并行的问题。参与设计 **LeadAgent 结构化规划、Schema 校验与 DAG 依赖调度**，专家 Agent 只负责执行；结果聚合前引入仲裁校验层检测跨 Agent 输出矛盾。复杂任务平均耗时 **60s → 35s（↓42%）**。

  - **多模态检索**：针对传统文本 RAG 系统性答不出硬件图表曲线类问题。设计视觉原生检索方案：跳过 OCR，用 **ColQwen2** 对整页图像做 Patch 级多向量 Embedding，通过 **ANN 粗排 + MaxSim 精排**定位答案区域，分数不足时降级文本双路兜底。图表类问题准确率 **35% → 73%**。

  - **结构化抽取管线**：构建硬件数据知识库，采用**多量纲单位归一化、数字／扫描 PDF 分流与跨表交叉校验**后入库 PostgreSQL；查询侧使用**预置 SQL 模板**，LLM 仅做参数抽取，规避幻觉与注入风险。抽取准确率 **62% → 91%**，支持跨文档精确范围查询。

  - **并发资源治理**：针对百余名用户共同使用时复杂任务挤占简单请求、重试请求级联占满资源池的问题，按模型调用、DB 连接和下游服务分类设置并发上限，通过用户间**公平轮转**替代全局 FIFO，并对重试请求降权隔离，使简单请求 **P95 延迟由 15s 降至 5s（↓67%）**。
