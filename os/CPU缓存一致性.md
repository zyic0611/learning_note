多核 CPU 各有自己的 L1/L2 缓存，同一内存数据可能被多核缓存，需要一致性协议避免脏读。

**四个状态：**

| 状态 | 含义 |
|--|--|
| **M**odified | 我改过了，与内存不一致，其他核没有这行 |
| **E**xclusive | 只有我有，与内存一致，没人改过 |
| **S**hared | 多核都有，与内存一致，都没改 |
| **I**nvalid | 已失效，不能用 |

**流程：** A 核要修改数据 → 广播通知其他核 → 其他核把该行标记为 **I** → A 核状态改为 **M**，直接在缓存里改 → 写回内存时才更新主存

**延伸**：Java 的 `volatile` 就利用这个机制，强制写操作让其他核缓存失效，保证可见性。
