|      | 分页            | 分段                    |
| ---- | ------------- | --------------------- |
| 划分方式 | 固定大小4KB，OS 管理 | 按逻辑单元（代码/数据/堆/栈），大小可变 |
| 优点   | 无外部碎片，内存利用率高  | 有语义，便于保护和共享           |
| 缺点   | 有内部碎片         | 有外部碎片                 |

现代 OS（如 x86）用**段页式**：先分段再分页，兼顾语义和利用率。

口诀：**分页解决碎片，分段提供语义**
