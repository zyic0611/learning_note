| 算法           | 特点                      | 适用场景           |
| ------------ | ----------------------- | -------------- |
| FCFS 先来先服务   | 按到达顺序，有护航效应             | 简单场景           |
| SJF 短作业优先    | 优先跑最短任务                 | 批处理系统          |
| 时间片轮转（RR）    | 轮流执行时间片                 | 交互式系统          |
| 优先级调度        | 高优先级先跑，可能饿死低优先级         | 实时系统           |
| HRRN 最高响应比优先 | `(等待时间+执行时间)/执行时间`，防止饿死 | 批处理系统          |
| **多级反馈队列**   | 多队列+动态调整优先级             | **现代 OS 主流思想** |

**多级反馈队列细节：**
- 多个队列，优先级从高到低，时间片从小到大
- 新进程进最高优先级队列；时间片用完没跑完就**降级**
- 低优先级队列只有高优先级队列全空才能运行
- 等太久会**提升优先级**，防止饿死
- 短任务响应快，长任务减少切换开销，I/O 密集型任务优先级会被提升
- Linux 实际用的是 **CFS（完全公平调度器）**，思想不同（基于虚拟运行时间），但 MLFQ 是理解调度的基础
