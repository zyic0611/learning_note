pi的核心是一个三层架构。

首先是 pi-ai 可以理解为模型层 

把不同的provider统一成稳定的模型调用协议 聚焦model context 调用参数 输出的流式事件



第二层是 pi-agent-core

就是a gen t-loop层 把一次llm响应组织为可持续行动的循环。但是这一层不能仅仅理解为react循环 包含更通用的运行时机制 包含一些runtime的内容

聚焦于 Agent state 、loop、工具执行 结果回写。



第三层是 pi-coding-agent

把通用agent变成可用的变成产品

聚焦于session 代码工具 cli/tui 压缩 扩展
