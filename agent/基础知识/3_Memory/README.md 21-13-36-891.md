# Agent Memory 学习路线（实习面试版）

## 学习目标

重点掌握 Agent 为什么需要记忆，以及一条信息如何经过：

```text
产生
→ 判断是否值得记
→ 写入合适的存储
→ 在需要时检索
→ 注入模型上下文
→ 更新、冲突处理或删除
```

不把 Memory 简化成“接一个向量数据库”，也不深入企业级存储平台和复杂记忆研究算法。

## 章节边界

| 章节 | 只负责回答 |
|---|---|
| 01 | Memory 是什么，完整生命周期是什么 |
| 02 | 当前任务中的有限上下文如何管理 |
| 03 | 跨会话长期保存哪些类型的信息 |
| 04 | 什么时候写、如何更新、冲突和遗忘 |
| 05 | 不同记忆应该放进什么存储 |
| 06 | 什么时候检索、如何筛选并注入上下文 |
| 07 | Memory 与 State、RAG 等概念的边界以及安全要求 |
| 08 | 如何评测，并通过一个项目证明掌握 |
