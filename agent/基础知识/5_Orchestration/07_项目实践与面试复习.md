# 项目实践与面试复习

## 需要学习

### 推荐项目

直接使用 SQL Agent 或业务查询 Agent 实践：

```text
用户输入
→ 意图路由
→ 参数澄清
→ Schema 检索
→ SQL Plan
→ SQL 生成
→ 确定性校验
→ 执行
→ 错误分支或有限修正
→ 结果生成
→ 最终回答
```

### 项目需要覆盖

- Node、Edge 和结构化 State。
- 规则路由与至少一个模型路由。
- 一个可复用 Subflow。
- 串行步骤和至少一组可并行步骤。
- 错误分支、Fallback 和终止状态。
- Checkpoint 与一次恢复场景。
- 一个 Human-in-the-loop 节点。
- 基础 Trace 和测试集。

Multi-Agent 不是必选；只有存在明确专业能力或权限边界时再加入一个 Specialist Agent。

## 项目验收标准

- 每个节点职责单一。
- 模型不能跳过安全、权限和验证节点。
- State 字段明确，不依赖自然语言猜测流程状态。
- 所有分支有终止路径。
- 失败后不会无限循环。
- 可以从日志定位路由、节点和恢复问题。

## 面试需要能回答

- Orchestration 与 Reasoning、Planning 有什么区别？
- Workflow State 与 Memory 有什么区别？
- Router 与 Planner 有什么区别？
- 如何实现串行、并行、分支和汇合？
- 为什么需要 Checkpoint？
- Human-in-the-loop 如何暂停和恢复？
- 什么情况下值得使用 Multi-Agent？
- 如何评测一个 Agent Workflow？
