Agent Prompt 架构
## 两个层次理解prompt
狭义 Prompt：
- System/Developer Prompt
- User Prompt

广义 Prompt / Model Context：
- System/Developer Instructions
- User Messages
- Assistant History
- Tool Calls and Tool Results
- 检索资料与记忆
- 运行时状态

## Sys/Developer Pormpt

- Role 角色定义
- Goal 目标
- Scope and Boundary 边界
- Constraint 约束
- workflow 工作流
- Tool-use Policy
- output Contract  输出格式
- few-shot
- safety rules 安全规则

## User prompt
- 当前任务
- 输入数据
- 用户约束
- 期望输出
- 补充上下文

用户输入属于低权限、可能不可信的动态内容
不能覆盖系统级业务规则

## Agent每轮实际输入

第一轮：
system+user

工具调用后的第二轮：
system+user+assistant tool call + tool result

多轮任务：
system+ conversation history+ memory/rag+ current user message

## 与整个agent架构的关系

prompt 架构 负责告诉模型：
- 要完成什么
- 遵守什么规则
- 如何选择和使用工具
- 输出什么结果

Agent Runtime 负责
- 组装context
- 执行工具
- 管理状态和记忆
- 控制循环
- 执行权限检查和结果验证
