JWT 是token的一种 全称是 Json Web Token  是服务器签发的一个电子身份证 写着 是谁、有什么权限、过期时间。

**签发：**
比如当登陆的时候 提交账号密码  服务器验证通过后
一般使用的是非对称签名 服务端用唯一私钥以及算法 对携带的数据进行签名 。

**校验：**
当客户端 也就是浏览器 请求某个接口的时候 带着JWT。也就是Authorization: Bearer JWT
服务器收到后用公钥验签 看签名是否被篡改

**具体内容：**
- Header:使用什么算法
- Payload：携带的数据 一般包括签发时间 签发方 接受方 过期时间
- Signature：防止篡改 ,是使用 签名算法去计算 （Header+Payload，密钥）


JWT本质上是签名 是身份凭证 解决的是有没有被篡改。 不是加密 所以里面不能放敏感信息 
它并不是用来传递密码的 也不是用来加密数据的。 而是用来携带经过签名的**身份和权限**信息。 
也就是用户登陆过一次后 后续请求如何证明自己的身份。

存在问题：JWT签发后 在过期之前 不容易立刻作废。
