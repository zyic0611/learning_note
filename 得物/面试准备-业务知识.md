## 一、得物是啥（3 句话）

- 潮品电商 + 社区：潮鞋、潮服、美妆、数码等，用户以年轻人（Gen Z）为主
- 核心模式 C2B2C「先鉴别、后发货」：卖家寄货 → 平台鉴别 → 买家收货，鉴别是核心壁垒
- 电商特点：**高客单价、低频**（对比淘宝的薄利多销），所以投放更看重「找对的人」，而不是海量拉新

## 二、这个平台是啥（一句话）

**增长投放平台**：管理「买量」全链路的系统——对外对接抖音/腾讯/B站/小红书等广告渠道，对内管计划、人群、出价、素材、数据。

链路很简单：建计划 → 出价 → 曝光 → 点击 → 安装 → 注册 → 首单 → 留存。

两个 JD 点名、知道是啥就行：

- **RTA**：广告平台竞价时实时问广告主「这个用户要不要、出多少价」，广告主用自己的数据（是否已安装、历史消费）实时回答。价值：精细化拉新，不浪费预算在已有用户身上
- **AB 实验**：投放策略（出价、人群、素材）上线前做对照实验验证效果

## 三、Agent 在这个平台的用处（重点）

投放运营的日常工作：**看数据、调计划、写复盘**。全是重复性 + 数据密集型工作，这正是 Agent 的机会点。

1. **智能数据分析**——最刚需
   - 运营用自然语言问数："昨天抖音渠道 ROI 为什么掉了？"
   - Agent 自己查数、对比、归因、给结论，替代人工拉表
2. **策略生成 / 自动化运营**
   - Agent 盯盘：按历史规律给出价、预算调整建议，甚至自动执行
   - 异常告警："某计划消耗异常"自动发现并处理
3. **素材与文案生成**
   - 广告文案、创意批量生成；行业已在做：阿里妈妈万相台、腾讯广告「妙思」、Meta Advantage+ 都是 AI 投放
4. **复盘自动化**
   - 日报/周报自动生成：数据汇总 + 原因分析 + 下周建议

**一句话总结**：投放平台本质是「人看数据、人做决策」的系统，Agent 的价值是把「看数据和做低层次决策」自动化，让人只做策略判断。
