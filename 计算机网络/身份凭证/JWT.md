JWT 是token的一种

全称是 Json Web Token  是服务器签发的一个电子身份证 写着 是谁、有什么权限、过期时间。

签发：

比如当登陆的时候 提交账号密码 服务器验证通过 签发JWT。

然后服务器用自己的唯一密钥 计算出一个签名 最后JWT有三部分

Header.Payload.Signature。

理解为 计算签名的算法  用户信息 签名。

校验：

当客户端 也就是浏览器 请求某个接口的时候 带着JWT。也就是Authorization: Bearer JWT

服务器收到后做两件事

1. 用自己的密钥 重新计算出一个签名
2. 比较和JWT里面的签名。

只要一致 就说明内容没有被篡改 服务器就知道用户、权限。 如果攻击者修改了信息  则服务器计算出来的签名就变了。但是JWT里面的签名还是旧的 校验就失败了。



具体内容：

Header:使用什么算法

Payload：携带的数据 一般包括签发时间 签发方 接受方 过期时间

Signature：防止篡改 ,是使用 签名算法去计算 （Header+Payload，密钥）



JWT本质上是签名 不是加密 所以里面不能放敏感信息 解决的是有没有被篡改 一般放在Token里。

它并不是用来传递密码的 也不是用来加密数据的。 而是用来携带经过签名的身份和权限信息。 也就是用户登陆过一次后 后续请求如何证明请求方是谁。



问题：JWT签发后 在过期之前 不容易立刻作废。
