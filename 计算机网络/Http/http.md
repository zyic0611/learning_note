HTTP 本身是无状态协议。

HTTP1.0 是短连接，一次通信就断开，多次访问需要反复建立 TCP 连接。 

HTTP1.1 默认支持长连接，一条 TCP 连接可以多次收发请求，但是请求串行排队，存在 HTTP 层的队头阻塞。 

HTTP2 仍然基于 TCP，采用二进制分帧和多路复用，在一条 TCP 连接上并发多条独立请求，解决了 HTTP 层面的队头阻塞；并且引入 HPACK 头部压缩，减少重复头部传输。但是底层是 TCP，依然存在 TCP 层面的队头阻塞。 (tcp丢包就会引发)

HTTP3 改用 UDP，基于 QUIC 协议实现可靠传输，彻底解决了 TCP 带来的队头阻塞，同时握手延迟更低，性能更好。
