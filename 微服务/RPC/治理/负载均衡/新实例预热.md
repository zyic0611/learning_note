**新实例不能一上来就吃满流量，要"预热"、慢慢加。**、

要点：

- 为什么不能直接满流量：
    
    - JVM/进程**冷启动**：类没加载、JIT 没编译、连接池没建
        
    - 缓存是空的 → 全打到后端，自己也慢
        
    - 一上来就被压满 → 可能直接被打挂
        
- 做法：**渐进式放量（slow start / warm-up）**
    
    - 给新实例一个**由小到大的权重**，随时间或请求数逐步升到正常
        
    - 期间负载均衡按这个动态权重分配
        
- 配套：
    
    - 健康检查**通过后**才开始接流量（先过准入，再预热）
        
    - 预热期间权重低，出错也好控制
        

一句话总结：**新实例先过健康检查，再按"权重从低到高"逐步放量，防止冷启动被打挂。**
