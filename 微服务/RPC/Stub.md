Stub（存根）就是远程服务在客户端本地的一个“代理对象”，让你看起来像是在调用本地方法。

客户端只需要拿到这个stub 直接调用方法就行     

stub内部 封装了方法名、参数成对象 序列化 网络发送到服务端 

stub把远程调用伪装成本地方法调用 屏蔽了网络通信、序列化等底层细节

Stub 是客户端侧代表远程服务端的服务的代理对象，由 RPC 框架通过 IDL 代码生成、动态代理或其他机制提供。


## 实现

不同RPC框架的实现不同 

比如 Thrift / gRPC 用的就是 IDL + 静态代码生成

有些 框架就是动态代理 还有一些框架就是 混合

```
客户端代理对象实现方式
      │
      ├── IDL + 静态代码生成 → Stub
      │
      ├── 动态代理 → Proxy
      │
      └── 混合方式
```


## 核心职责：

- 方法+参数 序列化为 RPC请求
- RPC响应 反序列化为 返回值
- 服务端异常 翻译为 客户端异常
- 网络/超时等通信问题 转换为 RPC通信异常


所以业务代码的视角   
- RPC调用成功 stub拿到服务端返回结果 反序列化为返回值
- 业务失败 返回业务异常
- 通信失败 抛RPC/网络异常
