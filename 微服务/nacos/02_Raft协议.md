## 持久化实例

**什么是持久化实例？** 这种实例注册上去后，哪怕它自己宕机了，Nacos 也**绝对不会**把它从注册表中剔除，只会把它的状态标记为不健康。它必须由运维人员通过 API 手动注销。

**应用场景在哪？** 比如大厂里的一些传统硬件负载均衡器（F5）、或者不能动态感知 IP 变化的旧系统（数据库主从节点配置等）。这些配置属于“基础元数据”，丢了会引发极其严重的故障，所以**宁可 Nacos 短暂不可用，也绝不能出现数据脑裂或丢失**。

**底层协议：** 为了保证强一致性，Nacos 引入了业界大名鼎鼎的 **Raft** 协议。数据不仅要在内存里，还要持久化到**磁盘**上（本地文件系统），并且必须要集群**半数以上**节点同意，数据才算写入成功。

## 适用

核心配置/非微服务节点不能乱变，所以用 **持久化实例 + CP (Raft) + 磁盘**，追求绝对的安全和一致。
