Netty 是一个基于 Reactor + I/O 多路复用的、协议无关的异步网络编程框架。 任何需要高并发网络 I/O 的产品都可以把它当作底层地盘。

IO模型为： Reactor 模式 + I/O 多路复用（Linux 下用 epoll ，macOS 用 kqueue，Windows 用 select）

线程模型为：EventLoopGroup（少量 IO 线程） + 业务线程池（非netty的内容 用户或者rpc框架配置的）

协议栈：不绑定任何协议。 通过pipeline +可插拔 Codec 支持任意协议（HTTP/1.1、HTTP/2、WebSocket、Thrift、gRPC、MQTT、Redis、自定义二进制…）

扩展点：责任链和handler

总结： **Java 领域里，但凡"高并发 + 自定义协议 + 异步 I/O"的场景，
底层大概率是 Netty。**

## 使用场景
替换一下协议之类的 就可以是一个应用。 一般用的都是应用 netty是应用的底层实现框架。
- RPC 框架：Dubbo、Kitex、gRPC-Java、Thrift
- API 网关：Spring Cloud Gateway (WebFlux + Reactor Netty)
- 消息中间件：RocketMQ Broker/Client
