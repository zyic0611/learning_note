记忆系统 主要是把 长期经验、项目知识、代码文档 加工成可以检索的上下文。 按需给Agent。



整体四层流水线：

信息源 索引层  检索层 agent使用层。



## 信息源

管理两类知识

- **经验记忆**：规则、知识、决策、模式
- **项目材料**：代码和文档

经验分三级： 个人习惯、项目、team（Git同步）



## 索引层

经验记忆主要存进 SQLite

项目层记忆 以markdown文件为主 、Sqlite只存储索引

代码和文档被切成小块 建立关键词和向量索引。



所以数据库损坏不会丢失项目知识 里面只存索引 索引负责搜索 可以随时重建。



## 检索

每次检索走两条路线。

- FTS5/BM25 擅长精确术语、函数名、错误信息
- 向量检索： 相似语义

最后合并 去重

原则是 关键词优先 向量结果补充



## Agent使用层

当Agent工作的时候 产生新的规则、决策

写入记忆 更新代码文档索引



强调两个工程原则

- 后台增量更新 文件变化的时候 只更新受影响的部分
- 向量服务失败的时候 自动退化为关键词搜索；索引更新失败也不阻塞 Agent
