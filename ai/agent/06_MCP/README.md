# MCP 学习目录

面向 Agent 大厂实习：重点是能独立接入、开发、评测并安全上线 MCP，而非背诵协议细节。

## 学习顺序

1. `01_总体概念与Agent工具生态.md`
2. `02_协议核心与Client_Server架构.md`
3. `03_Tools_Resources_Prompts.md`
4. `04_传输_会话与生命周期.md`
5. `05_开发一个MCP_Server.md`
6. `06_Agent集成_工具选择与执行.md`
7. `07_认证_授权与安全边界.md`
8. `08_可观测性_评测与可靠性.md`
9. `09_项目实战与面试.md`

## 目标产出

- 能实现一个带鉴权、分页、错误处理的 MCP Server。
- 能让 Agent 通过 MCP 调用多个外部系统，并处理失败与人工确认。
- 能用成功率、工具调用正确率、时延、成本和安全测试集评估它。
