# 项目实战与面试

## 推荐项目

企业数据分析 Agent：

- MCP Server 封装业务数据库与知识库。
- Agent 自动选择检索、指标查询和报告生成工具。
- 高风险查询走权限校验与人工确认。
- 展示评测集、调用 Trace、失败案例、成本与时延数据。

## 必会问题

- MCP、Function Calling、OpenAPI 各自解决什么问题？
- 怎样设计一个模型更容易正确调用的 Tool？
- 如何处理 Server 不稳定、超时和重复写入？
- 如何防止 MCP 成为权限扩大和 Prompt Injection 的入口？
- 你的项目如何证明 MCP 接入真的提升了任务成功率？
