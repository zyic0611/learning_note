是模型以前生成的内容  是模型的历史消息

主要是为了让模型知道：
- 自己以前说过什么
- 完成了哪些步骤
- 向用户承诺了什么
- 任务进展到哪里
- 是否调用过工具
- 当前对话的状态是什么

而且历史消息也不绝对事实 主要是
- 模型猜测
- 工具调用被误读
- 用户后来修改了事实
- 历史消息被伪造或注入
因此历史消息并不等价于 真实世界状态

真实状态应该优先来自
- 数据库
- 工具结果
- 后端服务
- 当前用户确认
- 权威系统

## 影响llm action

历史消息可能影响模型行为 如果历史消息中有错误 llm可能会继续沿用

历史上下文带来错误记忆 

解决方案：
1. 对事实进行结构化存储
2. 将长期记忆和聊天记录分离
3. 关键事实每次从数据库读取
4. 允许用户纠正记忆
5. 给事实添加来源和时间
6. 不把llm的推测写入长期记忆
