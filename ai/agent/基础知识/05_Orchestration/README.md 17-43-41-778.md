# Agent Orchestration 学习路线

## 学习目标

面向 Agent 实习面试，重点掌握：

```text
如何把模型、工具、规则、人工和子 Agent
组织成可控制、可恢复、可观察的执行流程
```

## 推荐顺序

1. `01_总体概念与职责边界.md`
2. `02_Workflow节点边与状态.md`
3. `03_路由分支与子流程.md`
4. `04_执行调度与状态恢复.md`
5. `05_Human_in_the_loop与Multi_Agent.md`
6. `06_可靠性可观测性与评测.md`
7. `07_项目实践与面试复习.md`

## 唯一归属原则

| 主题 | 主归属 |
|---|---|
| Orchestration 与其他模块边界 | 第 1 章 |
| Node、Edge、State、Workflow | 第 2 章 |
| Router、Branch、Fallback、Subflow | 第 3 章 |
| 串行、并行、依赖、Checkpoint、Resume | 第 4 章 |
| 人工审批、Agent 路由与 Handoff | 第 5 章 |
| 错误恢复、Tracing 和评测 | 第 6 章 |
| 综合项目和面试表达 | 第 7 章 |

## 暂不深入

- 通用分布式工作流引擎实现。
- 大规模多 Agent 自组织和协商。
- 复杂共识协议。
- 企业级调度平台和资源编排。
