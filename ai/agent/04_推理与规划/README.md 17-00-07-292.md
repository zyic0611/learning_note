# Agent 推理与规划学习路线

## 学习目标

面向 Agent 实习面试，重点掌握：

```text
任务分析与拆解
→ 根据环境动态行动
→ 制定并维护计划
→ 验证和有限修正
→ 根据任务选择合适模式
```

## 推荐顺序

1. `01_总体概念与边界.md`
2. `02_推理脚手架与任务拆解.md`
3. `03_ReAct与自适应工具推理.md`
4. `04_Plan_Execute与动态重规划.md`
5. `05_Reflection验证与自我修正.md`
6. `06_模式选择与混合架构.md`
7. `07_评测项目与面试复习.md`
