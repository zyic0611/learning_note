## quey understanding 金标

输入是用户问题 

输出是 意图 指标 维度 时间 槽位

作用是 验证 Query Parsing是否正确

## Schema Linking 金标

输入是 Query

输出是 期望召回的表、字段

作用是 验证 Schema Recall 是否准确

## SQL Generation 金标

输入是 Query

输出是 SQL 或 SQL AST

作用是 验证 SQL 生成质量

## SQL Policy 金标

输入是 Query

输出是 PASS / BLOCK / REWRITE

作用是 验证 SQL 治理是否生效

## Multi-turn 金标

输入是 多轮对话

输出是 每轮上下文状态、槽位、Topic

作用是 验证记忆与上下文继承

## RAG Retrieval 金标

输入是 Query

输出是 应召回的文档、规则、示例

作用是 验证检索效果

## Answer 金标

输入是 SQL 结果

输出是 最终自然语言回答

作用是 验证回答是否符合业务口径
