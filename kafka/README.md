# Kafka 原理学习骨架

基于已有 RabbitMQ 知识，按「整体模型 → 存储 → 写入 → 消费 → 复制 → 一致性 → 问题推演」学习。

- 按目录与文件编号推进，一次只学一个文件，理解后再进入下一点。
- **【重点】**：优先吃透；其余内容用于补齐机制。
- 单篇展开顺序：为什么需要 → 链路或状态机 → 失效边界 → RabbitMQ 对照。
- 学习状态区分「待学习」「已展开，待理解确认」「已学习，用户已确认」，按确认结果推进。
- RabbitMQ 对照默认指常规 AMQP 队列；Streams 另行区分。
- 集群管理以 KRaft 为主，ZooKeeper 只作为历史背景。
