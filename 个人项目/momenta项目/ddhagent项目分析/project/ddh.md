momenta

核心参与项目：DDH Multi-Agent 智能助手平台

项目简介：面向自动驾驶硬件研发部门的企业级 AI 助手，接入飞书群聊，覆盖器件选型、项目管理、测试验证等场景。作为核心开发者，负责 Multi-Agent 任务编排与器件选型领域的多模态 RAG 系统建设。

技术栈：Python / FastAPI Claude Agent SDK / MCP ANN / MaxSim PostgreSQL / pgvector Redis

项目亮点：

Multi-Agent 架构：针对任务规划与执行强耦合导致单点故障、无法并行的问题。参与设计 LeadAgent 结构化规划、Schema 校验与 DAG 依赖调度，专家 Agent 只负责执行；结果聚合前引入仲裁校验层检测跨 Agent 输出矛盾。复杂任务平均耗时 60s → 35s（↓42%）。

视觉原生多路检索：针对传统文本 RAG 答不出图表曲线类问题，设计三路并行检索：BM25 精确召回、文本向量语义召回、视觉原生检索跳过 OCR 用 ColQwen2 Patch 级多向量 Embedding + MaxSim 精排定位答案区域，RRF 融合后多模态翻译层输出文字描述统一送主力 LLM，分数不足降级文本双路兜底。图表类问题准确率 35% → 73%。

Skill 生态与 MCP 接入:针对 Agent 即兴推理流程不稳定、存量系统硬编码接入难维护的问题，将硬件研发 SOP 抽象为 Skill 执行单元：步骤固定、必查项由代码保证、LLM 只在判断节点介入，沉淀 10+ 工作流；同时将项目管理、物料查询等存量服务封装为 MCP Server，Agent 动态发现与调用。


Agent 运行时治理：针对复杂任务多轮调用导致尾延迟、Token 成本及重试流量失控的问题，建立请求级执行预
算，统一限制最大轮次、累计 Token 与端到端超时；按模型、数据库及下游服务分级限流，以用户级公平轮转保障
简单请求，并对重试设置次数上限与降权隔离，使简单请求 P95 延迟由 15 s 降至 5 s（↓67%）。）
