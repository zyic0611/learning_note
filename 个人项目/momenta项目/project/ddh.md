momenta

核心参与项目：DDH Multi-Agent 智能助手

项目简介：面向自动驾驶硬件研发部门的企业级 AI 助手，接入飞书群聊，覆盖器件选型、项目管理、测试验证等场景。
个人职责：作为核心开发者，负责 Multi-Agent 任务编排、器件选型多模态 RAG 及 Agent 运行时治理等核心模块建设。

技术栈：Python / FastAPI / Claude Agent SDK / MCP / BM25 / ANN / MaxSim / PostgreSQL / pgvector / Redis

项目亮点：

Multi-Agent 任务编排：参与设计 LeadAgent 结构化规划、Schema/数据流校验与 DAG 调度，实现无依赖节点并行和失败分支局部恢复；聚合前引入仲裁层检测跨 Agent 输出冲突。复杂任务平均耗时由 60s 降至 35s（↓42%）。

多模态RAG：负责器件选型知识库检索链路建设，解决传统文本 RAG 难以回答图表、曲线类问题的局限；搭建 BM25、向量与视觉原生三路并行检索，使用 ColQwen2 生成 Patch 级多向量 Embedding，通过ANN 粗排 + MaxSim 定位相关区域，并以 RRF 融合多路结果；使图表类问题准确率由 35% 提升至 73%。

Skill 生态与 MCP 接入:将硬件研发 SOP 抽象为可复用 Skill，通过代码固化执行步骤和必查项，仅在判断节点引入 LLM，降低 Agent 即兴规划带来的流程波动，累计沉淀 10+ 标准化工作流；将项目管理、物料查询等存量服务封装为 MCP Server，支持 Agent 动态发现和统一调用。

Agent 运行时治理：参与建立请求级执行预算，统一约束最大轮次、累计 Token 和端到端超时；针对复杂任务挤占资源的问题，按模型、数据库及下游服务实施分级限流，引入用户级公平调度，并为重试设置次数上限及降权隔离机制，使简单请求 P95 延迟由 15 s 降至 5 s，降低 67%。
