- **核心参与项目**：DDH Multi-Agent 智能助手平台

- **项目简介**：面向自动驾驶硬件研发部门的企业级 AI 助手，通过飞书群聊服务百余名研发人员，覆盖器件选型、项目管理与测试验证等场景；负责 Multi-Agent 任务编排及器件选型领域的多模态 RAG 建设。

- **技术栈**：Python / FastAPI / MCP / BM25 / BGE / ANN / MaxSim / PostgreSQL / pgvector / Redis

- **项目亮点**：

    - **Multi-Agent 任务编排**：参与设计并落地 Multi-Agent 任务编排架构，基于 **Lead Agent 结构化规划、Schema/数据流校验与 DAG 依赖调度**，支持专家子 Agent 独立执行、无依赖节点并行及失败分支局部恢复；在结果聚合前引入 **仲裁层** 检测跨 Agent 输出冲突，使复杂任务平均耗时由 **60 s 降至 35 s**。

    - **多模态 RAG**：构建 **BM25、文本向量与视觉原生三路并行检索**，使用 ColQwen2 对整页图像生成 Patch 级多向量表示，通过 **ANN 粗排 + MaxSim 精排**定位答案区域，并以 RRF 融合多路结果；低置信度时降级至双路文本检索，使图表类问题准确率由 **35% 提升至 73%**。

    - **Skill 生态与 MCP 接入**：将硬件研发 SOP 抽象为可复用 **Skill 执行单元**，通过代码固化执行步骤和必查项，仅在判断节点引入 LLM，累计沉淀 **10+ 标准化工作流**；将项目管理、物料查询等存量服务封装为 **MCP Server**，支持 Agent 动态发现和统一调用。

    - **Agent 运行时治理**：参与建立**请求级执行预算**，统一约束最大轮次、累计 Token 和端到端超时；按模型、数据库及下游服务实施**分级限流与用户级公平调度**，并为重试设置次数上限及降权隔离机制，使简单请求 **P95 延迟由 15 s 降至 5 s（↓67%）**。
