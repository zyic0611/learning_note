# 城市应急调度平台

**项目时间：2025.03 - 2026.07**

- **项目简介**：面向暴雨防汛、大型活动等突发场景的应急工单调度平台，根据救援人员的位置、技能与负载完成任务匹配，支持并发抢单、超时重派与可靠落库。

- **技术栈**：Java / Spring Boot / MySQL / Redis / Lua / RabbitMQ

- **项目亮点**：

    - **候选人匹配与优先级调度**：基于 **Redis GEO** 筛选工单周边人员，结合技能、在线状态与负载完成候选人排序；使用 **Redis ZSet** 管理待调度工单，根据事件等级和等待时长动态调整优先级，避免低优先级工单长期饥饿。
        
    - **原子抢占与超时重派**：使用 **Redis + Lua** 原子校验工单状态、技能名额、人员容量及重复抢单，生成带 Token 的短时技术预占；异步落库成功后开启 5 分钟确认租约，由 RabbitMQ 延迟消息触发条件回滚，并通过 Token 隔离新旧租约，避免迟到消息误释放有效名额。
        
    - **异步落库与最终一致性**：使用 **RabbitMQ** 解耦抢单与数据持久化，以本地消息表、**Publisher Confirm**、**手动 ACK** 和数据库唯一约束实现至少一次投递下的业务幂等；通过 Redis 待确认事件、定时补偿及状态对账，修复跨 Redis 与 MySQL 的异常空窗。
