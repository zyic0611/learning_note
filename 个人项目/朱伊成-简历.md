## 个人项目
::: start
**城市应急调度平台**
:::
**独立开发｜开发中**
::: end

- **项目简介**：面向暴雨防汛、大型活动等突发场景的应急工单调度平台，根据救援人员的位置、技能与负载筛选候选人，支持优先级调度、并发抢单、处理租约、超时重派与异步落库。

- **技术栈**：`Java / Spring Boot` `MySQL` `Redis / Lua` `RabbitMQ`

- **项目亮点**：

    - **候选人匹配与优先级调度**：基于 **Redis GEO** 对工单周边救援人员进行地理位置粗筛，结合技能标签、在线状态与当前负载完成候选人过滤及综合排序；使用 **Redis ZSet** 管理待调度工单，并根据事件等级与等待时长动态调整优先级，避免普通工单长期饥饿。
        
    - **原子抢占与处理租约**：使用 **Redis + Lua** 将候选资格、工单状态、人员容量及重复抢单校验封装为原子操作，抢单成功后生成带 Token 的处理租约；通过 RabbitMQ 延迟消息检测租约状态，对超时未处理的工单校验租约 Token 后释放人员容量并重新调度，避免旧消息误释放新租约。
        
    - **可靠异步与最终一致性**：通过 **RabbitMQ** 解耦抢单受理与数据持久化，结合 Publisher Confirm、手动 ACK、死信重试及业务幂等键处理消息丢失与重复消费；记录 Redis 已抢占但未落库的待确认事件，由定时任务扫描补发，并通过状态对账修复 Redis 与 MySQL 不一致。
