## AtomicLong

是基于CAS的原子计数器 每次自增都直接竞争同一个变量 计数就代表着自增。 一般用于统计请求数 访问量 高并发下 都在竞争同一个CAS变量 会导致大量的自旋 CPU飙升 性能下降。

提供的是强一致性的结果 

## LongAdder

是用分段技术和最终求和避免CAS竞争的高并发计数器。

- base 
- `cell[]`

无竞争时 直接修改base 有的时候 进入分流机制 每个线程进入不同的cell 最后求sum 

空间换时间 并且sum不精确到瞬时值 也是弱一致性 

适用于 高并发写 计数器 不需要精确实时只  就是ConcurrentHashMap求size的思想
