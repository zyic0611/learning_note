## 保证可见性

JMM 就是java Memory Model 、java内存模型。 是一套 **规范**

规定在多线程下 一个线程对共享变量的写 什么时候对另一个线程可见 以及哪些重排序是允许的。

JMM中：

​	每个线程都会有自己的**工作内存**（CPU缓存、寄存器） 而变量的真实值存储在主内存中 普通变量被修改后 会先存在自己的工作内存中 不知道什么时候会同步到主内存中 导致其他线程读到旧数据

加上volatile后 就让变量马上写回**主内存** 并且读也是必须去主内存读

​	而工作内存 主内存 其实都是**抽象概念**。

JMM中 线程对变量的操作 总结为：

- 读：主内存 → 工作内存
- 写：工作内存 → 主内存（何时刷回，由 JMM 规则决定）
