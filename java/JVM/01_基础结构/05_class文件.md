字节码文件 内部有 静态常量池表。存储了两大类信息： 字面量和符号引用

## 字面量：

接近常量的概念 存储的是程序中写死的值。

文本字符串 `String s = "Hello World";`，其中的 `"Hello World"` 就会作为字面量存储在常量池中

final的基本数据类型常量：`static final int MAX_SIZE = 100;`，这里的 `100` 会直接以字面量的形式存入常量池

## 符号引用

符号引用就是用类名、方法名、字段名等信息描述“我要找谁”。

## 静态文件到运行时的演变

也就是字节码文件和jvm内存结构的关系

1、静态阶段 ：

​	此时在硬盘上，编译完的 .class文件里有一个**静态的常量池表** 里面装满了字面量和符号引用

2、类加载阶段

​	JVM把类 加载到内存的时候 会把静态的常量池表的内容 包括字面量和符号引用  加载到 方法区（元空间）的运行时常量池中，也就是栈帧方法引用所指向的区域。便于寻找符号引用

3、解析阶段

​	类加载过程 JVM会把一部分静态方法、私有方法、父类构造器等运行期不会改变的 替换为直接引用 该阶段也叫静态解析

4、运行时期

​	对于剩下的那部分无法在加载阶段确定的符号引用，它们会一直以符号引用的形式保留在运行时常量池中。直到程序真正执行到那一行指令时，才会被转换为直接引用。这就是**动态链接。
