 类加载的全过程 发生在生命周期的 **类第一次被加载的过程**。 此时程序已经运行了  JVM也执行了。

被加载到虚拟机 会经历三个主要的阶段 

加载 链接 初始化 

使用和卸载两个阶段是加载后的事情。

链接包括 验证 准备 解析 三个部份。

## 加载

完成三件事

- 通过类的**全限定名**获取定义此类的二进制字节流 来源可以是本地 Class 文件、网络、动态代理生成的字节码等）
-  将这个字节流所代表的静态存储结构转化为方法区的运行时数据结构
- 在内存中生成一个代表这个类的 `java.lang.Class` 对象，作为方法区这个类的各种数据的访问入口。

## 链接

链接阶段是保证底层运行安全和内存结构初始化的关键。

- **验证**： 确保Class 文件的字节流中符合JVM的规范
- **准备：** 为类的静态变量分配内存 并且设置0值
- **解析**：把常量池里的符号引用 转化为直接引用

## 准备阶段的细节

如果是 `public static int value =123` 那么准备阶段后 分配的初始值是0 123是在初始化阶段才执行的

如果被final修饰 `public static final int value = 123` 并且字段属性表中存在`ConstantValue` 属性，在准备阶段变量就会被初始化为 `123`。

总结 静态变量 先分配0值 在准备阶段 如果是 静态常量 则在这个阶段就赋值


## 初始化

初始化阶段 JVM才会执行字节码。

这个阶段是执行 类构造器`<clinit>`方法的过程。
