对象的结构为： `对象头 字段 对其填充`

所以java对象= 对象头+实例数据+对其填充

## 必须性

Java对象需要额外存储信息 来知道 

- 对象属于哪个类 
- 有没有加锁
- 有没有GC标记
- hashcode是多少
- 年龄是多少
- 锁的状态

## 整体结构

一个Object Header的完整结构为

- Mark Word：存储 锁状态 HashCode Gc年龄等
- Class Pointer 指向类元数据的指针
- 成员变量
- 对其填充

最核心的两部份就是 Mark Word 和 Class Pointer

## Mark Word

标记字段 是对象头里面的一块特殊区域  作用：存储对象运行时状态。

状态一般包括：

- hashCode
- GC年龄
- 锁状态
- 偏向锁线程ID
- 锁记录指针

重点 他不定存储所有东西 主要是根据对象当前状态 复用这一块内存。 

因为这些信息不可能同时存在

 一个对象可能没有锁 则markword可以存hashcode gc年龄

如果需要存锁指针 hashcode可以暂时存别的地方 

所以mark word是一个多功能状态存储区域。

现在64位jvm下 markword一般是8字节 64位

## 锁

锁为什么在markword里

因为

```java
synchronized(user){

}
```

本质并不是给代码加锁 而是给对象加锁。 因为锁的入口就是对象

两个线程都执行 上面加synchronized的时候  jvm是判断 user这个对象有没有被哪一个线程占用。 所以需要一个地方保存锁状态 

## hashcode

hashcode为什么

因为 Object.hashCode()

JVM需要保存计算结果。

因为：对象hashCode：不应该每次重新计算。

所以第一次计算保存Mark Word里，以后需要直接读取。

## Class Pointer

jvm需要知道对象是什么类型的  当执行对象的类方法的的时候  需要找到指向 Class对象的指针
