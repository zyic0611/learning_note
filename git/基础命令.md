## 合并别人的代码 

比如我的分支是  feature/a 

别人是 features/b 

最后要合并到 develop

先切换到分支develop :  git checkout develop 然后拉取最新的 git pull 然后合并我的分支 git merge feature/a

如果冲突  git会在冲突的文件里标明 自己的代码和待合并的代码的一个冲突 我们可以人工审阅看出区别 修改后 比如修改init.py 修改后

手动把init.py加入暂存区 git add init.py

最后提交合并结果 git commit -m "xx"


## 远端覆盖本地

git fetch origin
git reset --hard origin/master
git clean -fd


|                                  |                                        |
| -------------------------------- | -------------------------------------- |
| `git fetch origin`               | 把远端最新记录拉下来（不改工作区）                      |
| `git reset --hard origin/master` | 本地 master 强制对齐远端 master，丢弃已跟踪文件的所有本地改动 |
| `git clean -fd`                  | 删除未跟踪的文件和文件夹（就是你报错里那批 `微服务/...`）       |
