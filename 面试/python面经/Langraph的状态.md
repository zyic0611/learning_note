请你介绍一下 LangGraph 的核心设计思想？State、Node、Edge（条件路由）分别是什么？为什么 Agent 需要有状态管理，而普通 Chain 不需要？



A：LangGraph 的核心思想是使用状态图来构建有状态 Agent 工作流。它把 Agent 拆分成多个 Node，每个 Node 负责一个具体操作，例如调用 LLM、调用工具或者执行业务逻辑；State 用于保存整个流程中的共享上下文；Edge 用于定义节点之间的流转关系，包括普通边和条件边。

相比传统 Chain 固定的串行流程，Agent 的执行路径通常是不确定的，需要根据 LLM 输出决定下一步动作，并且可能存在多轮循环。因此需要通过 State 管理历史消息、中间结果和工具调用结果，实现有状态的 Agent。
